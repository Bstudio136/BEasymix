# 🎛️ BEasymix Studio

Une application web locale et 100% client-side de mixage et mastering audio, inspirée de la plateforme easymix.io.

## ✨ Fonctionnalités
- **Sources** : Chargement de pistes (Voix, Instrumental, Adlibs) et enregistrement micro.
- **Traitement Audio** : EQ, compression, saturation, gate, réverbération, delay et autotune.
- **Mastering** : Normalisation LUFS (mesure avec K-weighting), limiteur et élargissement stéréo.
- **Export** : Téléchargement au format WAV (16/24/32-bit).
- **100% Local** : Aucune donnée n'est envoyée sur un serveur, tout est traité par le navigateur via la Web Audio API.

## 🚀 Déploiement
Ce projet est hébergé directement via **GitHub Pages**.
